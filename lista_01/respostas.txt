Questão 04

Foram identificados os seguintes erros no código do estudante:

#include <stdlib.h>; — Não deve haver ponto e vírgula no final de uma diretiva de pré-processador.
int Main{} — C diferencia letras maiúsculas e minúsculas. A função principal deve ser main. Além disso, os parâmetros da função são colocados entre (), e não entre {}.
( e ) no corpo da função — O corpo de uma função em C deve ser delimitado por chaves { }.
printf( Existem %d semanas no ano.,52); — A string de formato precisa estar entre aspas duplas, por exemplo: "Existem %d semanas no ano.\n".
cout << endl; — Essa é uma sintaxe de C++, não de C. Em C, a quebra de linha pode ser feita com \n.

Questão 08

O programa utiliza três sequências de escape:

\n — pula para o início da próxima linha.
\t — faz uma tabulação horizontal.
\" — imprime uma aspa dupla (").

Assim, a saída começa com uma linha em branco, seguida de uma tabulação e do texto "Primeiro programa" entre aspas.

Depois disso, system("PAUSE") exibe a mensagem de pausa do sistema operacional.

Questão 09

No primeiro printf, os argumentos '\n', '\t' e '\"' são constantes de caractere. Como o %c espera um caractere, cada valor é convertido para o caractere correspondente:

'\n' → quebra de linha;
'\t' → tabulação;
'\"' → aspas duplas.

Já no segundo printf:

printf("%c", "\"");


foi passada uma string (char *) para %c, que espera um caractere. Portanto, há uma incompatibilidade de tipo.

O correto seria:

printf("%c", '\"');


A saída pretendida é:

	"Primeiro programa"
