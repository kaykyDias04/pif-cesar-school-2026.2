Questão 01

a)
Diferenças entre while e do-while:
- No while, o teste é feito antes de executar o bloco (pré-testado). Se a condição for falsa de início, o bloco roda 0 vezes (mínimo de 0).
- No do-while, o teste é feito no final da iteração (pós-testado). O bloco sempre roda pelo menos uma vez antes de testar a condição (mínimo de 1).

b)
Quando usar cada uma:
- for: ideal quando sabemos o número de iterações com antecedência ou temos uma variável com passo fixo (como contar de 0 a 100 ou percorrer vetores). É mais elegante porque junta início, teste e passo no cabeçalho.
- while: ideal quando o número de voltas é incerto e pode nem precisar rodar nenhuma vez (como ler entradas até um sentinela ou até o fim de um arquivo).
- do-while: ideal quando precisamos rodar o bloco obrigatoriamente antes de testar a condição, como em menus interativos ou na validação de entrada de dados.

c)
Análise de 'while (condicao);':
Não é um erro de compilação, porque em C o ponto e vírgula representa uma instrução vazia (corpo nulo).
Porém, é um erro de lógica: se a condição for verdadeira, o programa entra em um loop infinito e trava, já que nenhuma instrução dentro do laço altera a condição.

Questão 02

a)
Porque a variável 'soma' foi declarada dentro do bloco do laço for ({ int soma = 0; ... }). Em C, variáveis de bloco têm escopo local e só existem dentro das chaves daquele bloco. Como o printf está fora do for, o identificador 'soma' não existe para ele.

b)
Porque como 'int soma = 0;' estaria dentro do laço, a variável seria recriada e zerada a cada volta. Em vez de acumular os quadrados, ela guardaria apenas o quadrado da iteração atual (1, depois 4, depois 9...), perdendo o total acumulado.

c)
Código corrigido (arquivo questao_02.c):

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int i;
    int soma = 0;

    for (i = 1; i < 10; i++) {
        soma += i * i;
    }

    printf("Soma final = %d\n", soma);
    system("PAUSE");
    return 0;
}

Conceitos:
- Escopo e Visibilidade: definem onde a variável pode ser acessada no código. Declarada dentro de um bloco { }, ela só é visível ali dentro. Para poder ser usada dentro do for e depois no printf, ela precisa ser declarada no escopo da função main.
- Tempo de vida: é o tempo que a variável fica alocada na memória. Variáveis locais normais são criadas quando o bloco começa e destruídas quando ele termina. Declarando soma fora do laço, seu tempo de vida dura por toda a execução da main, mantendo o valor acumulado entre as voltas.

Questão 03

a)
A sequência impressa no console é:
36	18	9	4	2	1	

Passo a passo:
- Começa em 36: imprime 36, divide por 2 -> 18
- 18: imprime 18, divide por 2 -> 9
- 9: imprime 9, na divisão inteira 9 / 2 dá 4
- 4: imprime 4, divide por 2 -> 2
- 2: imprime 2, divide por 2 -> 1
- 1: imprime 1, 1 / 2 dá 0
- 0: a condição a > 0 falha e o laço encerra.

b)
O trecho B lê caracteres com getch() a cada volta até que o usuário digite 'X'.
- Operação 'ch + 1': em C, caracteres são armazenados como números inteiros pela tabela ASCII. Somar 1 pega o próximo caractere do alfabeto/tabela (por exemplo, 'A' vira 'B', '1' vira '2').
- Parênteses em '(ch = getch())': são necessários porque o operador != tem precedência maior que =. Sem os parênteses, o C faria primeiro getch() != 'X' (gerando 0 ou 1) e guardaria esse booleano em ch, em vez de guardar o caractere digitado.

c)
Para sair do laço infinito for (;;) programaticamente:
- Usando o comando break dentro de um if de parada.
- Usando return para sair da função.
- Usando exit(0) para finalizar o programa.

Questão 04

a)
O comando break interrompe e encerra imediatamente o laço, saltando para a primeira linha de código fora dele, sem testar mais nada.

b)
O comando continue pula o restante do corpo do laço apenas na iteração atual e vai direto para a próxima volta. No laço for, ele salta imediatamente para a expressão de incremento (a 3ª parte do cabeçalho, como i++).

c)
Interrompe apenas o laço interno (o que contém o break diretamente). O laço de fora continua rodando normalmente.

Questão 05

a)
O laço executará exatamente 5 iterações.

Passo a passo:
1ª: i = 0, j = 10 (0 < 10 é V) -> após imprimir: i = 1, j = 9
2ª: i = 1, j = 9  (1 < 9 é V)  -> após imprimir: i = 2, j = 8
3ª: i = 2, j = 8  (2 < 8 é V)  -> após imprimir: i = 3, j = 7
4ª: i = 3, j = 7  (3 < 7 é V)  -> após imprimir: i = 4, j = 6
5ª: i = 4, j = 6  (4 < 6 é V)  -> após imprimir: i = 5, j = 5
Na próxima checagem, 5 < 5 é falso e o laço encerra.

b)
Saída de cada iteração:
i = 0, j = 10 | soma = 10
i = 1, j = 9 | soma = 10
i = 2, j = 8 | soma = 10
i = 3, j = 7 | soma = 10
i = 4, j = 6 | soma = 10

c)
Reescrita com a estrutura while:

int i, j;

i = 0;
j = 10;
while (i < j) {
    printf("i = %d, j = %d | soma = %d\n", i, j, i + j);
    i++;
    j--;
}

Questão 06

a)
O valor final de x impresso pelo printf será 6.

b)
O operador x++ é pós-fixado: ele primeiro usa o valor atual de x na comparação com 5 e só depois incrementa x em 1.
- x = 0: compara 0 < 5 (V), x passa para 1
- x = 1: compara 1 < 5 (V), x passa para 2
- x = 2: compara 2 < 5 (V), x passa para 3
- x = 3: compara 3 < 5 (V), x passa para 4
- x = 4: compara 4 < 5 (V), x passa para 5
- x = 5: compara 5 < 5 (Falso). Mesmo o teste falhando, o pós-incremento ainda é executado, levando x para 6!
Como o teste resultou em falso, o laço termina e o printf imprime o valor 6.

c)
Reescrita de forma clara:

int x = 0;

while (x <= 5) {
    x++;
}

printf("Valor final de x = %d\n", x);
